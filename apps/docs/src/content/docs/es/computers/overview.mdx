## Tres lugares distintos para trabajar

| Lugar | Para qué sirve | Qué necesitas |
|---|---|---|
| [VM Linux aislada](/es/office/computers/) | Darle al agente escritorio, navegador y archivos separados sin prestarle tu pantalla. | Core en una Mac Apple Silicon, recursos para la VM y permiso para ese agente. |
| [Navegador de Colonia](/es/office/browser/) | Navegar sitios, usar pestañas e iniciar sesión con entrega visible del control. | Nodo navegador del escritorio conectado. No es tu perfil personal del navegador. |
| [Tu propio escritorio](/es/devices/desktop/) | Trabajar en una app de tu ordenador cuando lo pides explícitamente. | Ordenador macOS o Windows compatible, nodo escritorio conectado y permisos del sistema. |

Mirar el panel remoto no mueve el trabajo al dispositivo donde lo ves. Revisa **dónde corren el core y el nodo**.
La VM Linux administrada corre junto al core. Un teléfono vinculado no se convierte en host de la VM.

## Empieza con la VM aislada

Abre la configuración del agente del proyecto y habilita **Ordenador aislado**. En su chat abre **Ordenador** y
elige **Usar el ordenador aquí**. Pide una tarea pequeña: «Abre el navegador de tu ordenador aislado y muéstrame
esta página pública; no envíes nada». El chat muestra la preparación y la pantalla cuando está lista.

En **Ordenadores** encuentras las pantallas de agentes habilitados, incluso apagadas. Sigue [VM Linux aislada](/es/office/computers/)
para preparación, recursos, apagado y terminal. No es un administrador general de VM Windows/Linux ni permite
crear una flota arbitraria de máquinas virtuales.

## Sesiones y aprobaciones

Usa **Tomar control** para iniciar sesión tú y después **Devolver control al agente**. No le pidas que escriba
contraseñas, códigos ni datos de pago. Un escritorio separado no autoriza instrucciones de un sitio, lectura de
archivos del host, envío de mensajes ni publicaciones sin la autorización habitual.

Si trabaja en otro lugar, deténlo y revisa el ordenador elegido por el chat antes de seguir. No copies archivos
privados al invitado solo para resolver una ruta confusa: primero aclárales los archivos y permisos necesarios.
