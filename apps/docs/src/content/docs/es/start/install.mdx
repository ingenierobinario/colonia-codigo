Colonia se instala en tu propio ordenador. Son unos minutos y no hace falta saber programar. Cuando termines, sigue con
[Conectar la IA](/es/start/connect-ai/) y [Primeros pasos](/es/start/first-steps/).

## Instalar la aplicación de escritorio

<Steps>

1. Descarga el instalador para tu sistema con el enlace que recibes con tu plaza. En Mac hay dos versiones: Apple silicon
   (los M1 y posteriores) e Intel.

2. Instálalo. Las aplicaciones todavía no están firmadas, así que tu sistema te avisará la primera vez. Es normal:

   - **macOS**: abre el archivo `.dmg` y arrastra **Colonia** a **Aplicaciones**. La primera vez, haz clic derecho sobre
     Colonia, elige **Abrir** y otra vez **Abrir**. Si sólo te ofrece tirarla a la papelera, ve a **Ajustes del Sistema ›
     Privacidad y seguridad**, baja hasta el aviso sobre Colonia y pulsa **Abrir igualmente**.
   - **Windows**: ejecuta el archivo `.exe`. Cuando SmartScreen diga que ha protegido tu PC, pulsa **Más información** y
     después **Ejecutar de todas formas**.
   - **Linux**: haz ejecutable el archivo AppImage y ábrelo con doble clic.

3. La primera vez te pregunta dónde funciona Colonia. Si es tu primera instalación, elige **Servidor** (quiere decir que
   Colonia funciona en este ordenador) y después **Solo desde este ordenador**, la opción más segura. El texto exacto de los botones puede variar.

4. Se abre el asistente de configuración. Síguelo con [Primeros pasos](/es/start/first-steps/).

</Steps>

<Aside type="caution" title="Si macOS dice que la aplicación está dañada">
Es la marca que macOS pone a lo descargado sobre una aplicación sin firmar, no un archivo roto. Abre la aplicación
Terminal, pega esta línea, pulsa Intro y vuelve a abrir Colonia:

```bash
xattr -dr com.apple.quarantine /Applications/Colonia.app
```
</Aside>

## Linux

El AppImage es un solo archivo: no hay nada que instalar. Dos cosas pueden frenarlo en un sistema reciente.

**No se abre y dice que necesita FUSE.** Ubuntu 22.04 y posteriores ya no traen la biblioteca con la que se abren los
AppImage. Instálala una vez:

```bash
sudo apt install libfuse2t64 || sudo apt install libfuse2
```

En Fedora es `sudo dnf install fuse-libs`, en Arch `sudo pacman -S fuse2` y en openSUSE
`sudo zypper install libfuse2`. Sin ella también puedes abrir Colonia: `colonia desktop` lo detecta, abre el archivo
desempaquetado (unos segundos más lento) y te dice la orden de arriba.

**Dice que está funcionando sin su aislamiento.** Ubuntu 24.04 y posteriores impiden que las aplicaciones creen el
aislamiento que Colonia usa para las páginas que abren tus agentes, salvo que la aplicación tenga un permiso propio.
Colonia no lo esconde: te avisa cuando se abrió sin el aislamiento y te da la única orden que concede ese permiso solo a
Colonia. Cópiala desde el aviso, ejecútala en una terminal y vuelve a abrir Colonia. No desactives la protección para
todo el sistema.

En GNOME no hay icono en la bandeja salvo que añadas una extensión, así que cerrar la ventana minimiza Colonia en vez de
ocultarla. Los atajos globales no funcionan en Wayland: asigna el atajo a Colonia desde los ajustes de teclado del
sistema.

## Instalar en un servidor

Sólo si quieres que Colonia funcione siempre, aunque apagues tu ordenador, y tienes un servidor propio. En esa máquina,
este comando instala Colonia y el comando `colonia`:

<InstallCommand labels={["macOS y Linux", "Windows"]} />

Después, `colonia setup --headless` termina la configuración y te da un código para emparejar tu aplicación o tu móvil. Todos
los detalles están en [Colonia en un servidor](/es/devices/server/).

## Dónde se guardan tus datos

Todo lo que guarda Colonia está en una carpeta de tu ordenador, `~/.colonia/v2`. Tus proyectos siguen donde estaban; Colonia
sólo les añade `AGENTS.md` y `.apc/`. Las claves van al llavero de tu sistema cuando lo hay. Más en
[Privacidad](/es/reference/privacy/).

## Actualizaciones

Colonia busca versiones nuevas cada pocas horas y, cuando hay una, muestra un aviso **Actualización** en la barra de
arriba. Tus datos se conservan. En Windows y Linux la versión nueva se instala sola; en macOS se abre el disco nuevo para
que arrastres la aplicación. En un servidor, `colonia upgrade --check` te dice si hay versión nueva y `colonia upgrade` la
instala. Con `COLONIA_UPDATES=off` se apagan las comprobaciones.

## Desinstalar

Desinstalar quita el programa. **Tus datos se quedan** en `~/.colonia/v2`: borra esa carpeta si quieres empezar de cero.

<Tabs syncKey="install">
<TabItem label="Aplicación de escritorio">

- **macOS**: cierra Colonia desde su icono en la barra de menú y arrastra **Colonia** de Aplicaciones a la papelera.
- **Windows**: Configuración › Aplicaciones › Aplicaciones instaladas › **Colonia** › Desinstalar.
- **Linux**: cierra Colonia y borra el AppImage. Si la instalaste con `colonia desktop`, el instalador con
  `--uninstall` la quita junto con su entrada del menú.

</TabItem>
<TabItem label="Servidor">

`colonia service uninstall` quita el servicio. Para quitar también el programa, vuelve a ejecutar el instalador con
`--uninstall` (en Windows, `-Uninstall`).

</TabItem>
</Tabs>
