## Abierta no significa actualizada

Una app puede conservar su vista mientras visitas otra pantalla de Colonia. Eso no vuelve vivos sus datos: la página
debe consultar una fuente o calcular valores nuevos explícitamente. Una vista con caché puede mostrar un resultado
viejo y actualizarlo después. Pide una fecha visible y estados de error o desactualización, no un número sin contexto.

Por ejemplo:

> Haz una app viva de estado de servicios desde esta API pública. Actualiza una vez por minuto mientras sea visible,
> conserva el último resultado correcto, muestra cuándo lo consultaste y márcalo desactualizado si falla. No inventes «en línea».

Para APIs privadas, indica servicio y datos necesarios, no el secreto en el chat. Configura el secreto del artefacto
aparte. La fuente puede rechazar pedidos, limitar consultas o no tener la API necesaria; Colonia no evita esos límites.

## Abre, sal y vuelve

Abre una app guardada desde **Apps**. Sigue ejecutándose al navegar dentro de Colonia hasta **Cerrar app**, salir de la
aplicación o desalojarla cuando otra necesite su lugar. El panel conserva hasta **seis apps abiertas**. Si está lleno,
puede cerrar una que no se muestra, empezando por la menos reciente. El punto en Apps indica que está abierta, no
que su fuente de datos esté conectada correctamente.

Un widget normalmente se cierra al salir de su vista completa. Para trabajar con él abierto, usa **Fijar en Apps**.
La acción **Abrir en una ventana nueva** mueve una app a su ventana; cerrarla la devuelve al panel. Abrir a pantalla
completa no cambia por sí solo el tipo widget/app guardado.

## Widgets vivos y visibilidad

Una página puede declarar aparte cuánto seguir viva oculta, por ejemplo para un contador. Este grupo tiene **tres**
lugares, independientes de las seis apps abiertas; las páginas ocultas pueden vencer o ser desalojadas. Las apps
deben pausar temporizadores y conexiones innecesarias cuando no se ven. No dependas de una aplicación oculta o
suspendida para ejecutar un trabajo importante a una hora exacta.

Estos límites describen el panel. No asumas que el teléfono, un enlace público o el escritorio cerrado conservan
la misma instancia viva. Los registros durables son distintos del iframe: la [memoria del artefacto](/es/office/artifacts/)
sobrevive al cierre; las variables sin guardar pueden perderse.

## El trabajo programado va en rutinas

Para «revisa cada mañana y avísame si cambió», usa una [rutina](/es/office/routines/), no un temporizador del artefacto.
La rutina se ejecuta en el core y tiene su resultado y política de avisos. Crear una app viva no crea una rutina,
un servidor permanente ni permiso para publicar o enviar mensajes.

## Si parece congelada

1. Revisa fecha del último éxito y error. La caché no prueba que la consulta sea nueva.
2. Muestra la app y reintenta actualizar; reconecta Colonia si está sin conexión.
3. Revisa origen de API declarado y secreto necesario. No quites las protecciones de aislamiento.
4. Reabre una app desalojada. Los registros guardados deberían seguir; compruébalo antes de borrar su memoria.
5. Pídele al agente que arregle el mismo artefacto en vez de crear otra copia sin registros.
