Colonia installs on your own computer. It takes a few minutes and you do not need to know how to code. When you finish,
go on to [Connect the AI](/start/connect-ai/) and [First steps](/start/first-steps/).

## Install the desktop app

<Steps>

1. Download the installer for your system with the link you get with your place. On a Mac there are two versions: Apple
   silicon (M1 and later) and Intel.

2. Install it. The apps are not signed yet, so your system warns you the first time. That is expected:

   - **macOS**: open the `.dmg` file and drag **Colonia** to **Applications**. The first time, right-click Colonia, choose
     **Open** and **Open** again. If it only offers the bin, go to **System Settings › Privacy & Security**, scroll to the
     notice about Colonia and click **Open Anyway**.
   - **Windows**: run the `.exe` file. When SmartScreen says it protected your PC, click **More info** and then **Run
     anyway**.
   - **Linux**: make the AppImage file executable and double-click it.

3. The first time, it asks where Colonia runs. On a first install choose **Server** (it means Colonia runs on this
   computer) and then the option to use it only from this computer, the safest one. The exact button text may vary.

4. The setup wizard opens. Follow it with [First steps](/start/first-steps/).

</Steps>

<Aside type="caution" title="If macOS says the app is damaged">
It is the mark macOS puts on downloads of an unsigned app, not a broken file. Open the Terminal app, paste this line,
press Return and open Colonia again:

```bash
xattr -dr com.apple.quarantine /Applications/Colonia.app
```
</Aside>

## Linux

The AppImage is one file: there is nothing to install. Two things can stop it on a recent system.

**It does not open and says it needs FUSE.** Ubuntu 22.04 and later no longer bring the library AppImages use to open.
Install it once:

```bash
sudo apt install libfuse2t64 || sudo apt install libfuse2
```

On Fedora it is `sudo dnf install fuse-libs`, on Arch `sudo pacman -S fuse2` and on openSUSE
`sudo zypper install libfuse2`. Without it you can still open Colonia: `colonia desktop` notices, opens the file unpacked
(a few seconds slower) and tells you the command above.

**It says it is running without its sandbox.** Ubuntu 24.04 and later stop apps from creating the sandbox Colonia uses
for the pages your agents open, unless the app has a permission of its own. Colonia does not hide it: it tells you when
it opened without the sandbox and gives you the one command that grants that permission to Colonia alone. Copy it from
the notice, run it in a terminal and open Colonia again. Do not turn the protection off for the whole system.

On GNOME there is no tray icon unless you add an extension for it, so closing the window minimises Colonia instead of
hiding it. Global shortcuts do not work on Wayland: bind the shortcut to Colonia in your system keyboard settings.

## Where your data lives

Everything Colonia keeps is in one folder on your computer, `~/.colonia/v2`. Your projects stay where they were; Colonia only
adds `AGENTS.md` and `.apc/` to them. Keys go to your system's keychain when there is one. More in
[Privacy](/reference/privacy/).

## Updates

Colonia looks for new versions every few hours and, when there is one, shows an **Update** notice in the top bar. Your
data is kept. On Windows the new version installs itself, and on Linux too when Colonia can write next to its AppImage (otherwise it
shows you the new file); on macOS the new disk image opens for you to drag the
app. On a server, `colonia upgrade --check` tells you whether there is a new version and `colonia upgrade` installs it.
`COLONIA_UPDATES=off` turns the checks off.

## Uninstall

Uninstalling removes the program. **Your data stays** in `~/.colonia/v2`: delete that folder if you want to start over.

<Tabs syncKey="install">
<TabItem label="Desktop app">

- **macOS**: quit Colonia from its icon in the menu bar and drag **Colonia** from Applications (the Applications folder in your home if you installed from the terminal) to the bin.
- **Windows**: Settings › Apps › Installed apps › **Colonia** › Uninstall.
- **Linux**: quit Colonia and delete the AppImage. If you installed it with `colonia desktop`, the installer's
  `--uninstall` removes it together with its menu entry.

</TabItem>
<TabItem label="Server">

`colonia service uninstall` removes the service. To remove the program too, run the installer again with `--uninstall` (on
Windows, `-Uninstall`).

</TabItem>
</Tabs>
