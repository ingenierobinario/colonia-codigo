A routine is work an agent does on its own, on a schedule. Here: every Monday at 09:00 Lucía reviews last week and
sends you the report.

## 1 · Create the routine

<Steps>

1. Open the project and go to **Routines**.
2. Click **New routine**.
3. **Name**: `weekly-report`.
4. **Agent**: the one who will write it (Lucía, for example).
5. **When**: **On a schedule**, only **Mon**, at **09:00**. If you prefer, **Write a cron** with <code style="white-space:nowrap">0 9 * * 1</code>.
6. In step **2 · Agent**, write the task (below).
7. **Save**.

</Steps>

<Shot name="case-routine" alt="Routines: the New routine dialog with the name, the agent, when it runs and its steps" caption="Routines › New routine" />

A good task for this report:

> Review last week in this project: finished tasks, blocked tasks and what is due this week. Write it in five lines,
> blocked first. If nothing changed, say so in one line.

## 2 · Make sure it reaches you

- The report goes through your interruption budget like any unasked message. If you want it **always** to arrive,
  turn on **Always arrives** in the routine.
- To receive it on your chat app (Telegram, WhatsApp…), choose it in **Settings › Interruptions › Chat app for
  notices**.

## 3 · Try it without waiting until Monday

In the **Routines** list, each routine has a button to run it now. Run it once, read the result and, if it doesn't
convince you, adjust the task and run it again.

<Shot name="routines" alt="The project's routines, and then the flows they run" caption="Routines and Flows" />

<Aside type="tip">
Rate it with 👍/👎 when it arrives: the routine gets its own numbers in the next run and adjusts what it says.
</Aside>
