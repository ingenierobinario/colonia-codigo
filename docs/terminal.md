# Terminal

`colonia` controla el servicio desde la línea de comandos. La lista completa está en `colonia --help`.

| Comando | Qué hace |
|---|---|
| `colonia` | Abre la consola interactiva |
| `colonia status` | Muestra el servicio, el equipo, los proyectos y los dispositivos |
| `colonia wizard` | Guía la configuración y el mantenimiento |
| `colonia open` | Abre el panel en el navegador |
| `colonia desktop` | Abre la aplicación de escritorio |
| `colonia doctor` | Explica por qué no responde el servicio y qué hacer |
| `colonia upgrade --check` | Comprueba si hay actualizaciones |
| `colonia mcp tools <servidor>` | Lista las herramientas de un servidor MCP |
| `colonia mcp check <servidor>` | Prueba la conexión con un servidor MCP |
